Developers

One POST in, one image out

Everything the Studio does is available over HTTP. Async by design: submit a job, poll it, fetch the image. Creator and Pro keys include API access.

Authentication

Send your key on every request:

x-api-key: lum_your_key_here

Generate

curl -X POST $LUMEN_API/generate \
  -H "Content-Type: application/json" \
  -H "x-api-key: lum_..." \
  -d '{
    "prompt": "a lighthouse in a storm, oil painting",
    "mode": "quick",          # "quick" (1 credit) or "full" (2 credits)
    "final_size": 1024,       # longest edge in px
    "aspect": "16:9"          # optional: 1:1, 4:3, 3:4, 16:9, 9:16
  }'

# -> 202 { "job_id": "abc123", "status": "queued", "credits": 199 }

Poll & fetch

curl $LUMEN_API/jobs/abc123 -H "x-api-key: lum_..."
# -> { "status": "running", "log": ["in_progress"] }
# -> { "status": "done", "image_url": ".../jobs/abc123/image" }

curl $LUMEN_API/jobs/abc123/image -o out.png

Endpoints

EndpointMethodWhat it does
/generatePOSTQueue a generation. Returns job_id and your remaining credits.
/jobs/:idGETJob status: queued → running → done | error, with a progress log.
/jobs/:id/imageGETThe finished image (PNG/JPEG bytes).
/creditsGETRemaining credits for your key.
/healthGETEngine status.

Notes

TopicDetail
PromptingDescribe what should be present — negative prompts are not supported. Put sign/label text in quotes; the engine renders real, legible text.
TimingDraft images typically land in seconds to a couple of minutes depending on engine load; Studio images take longer because of the multi-stage pipeline. Poll every few seconds.
Job retentionFetch your image promptly — job records expire 24 hours after completion.
Errors401 bad key · 402 out of credits · 502 engine error (you are not charged for failed jobs on poll-time errors).
