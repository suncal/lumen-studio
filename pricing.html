Questions

What's the difference between Draft and Studio mode?

Draft renders your prompt directly — fast and cheap, great for exploring. Studio runs the full pipeline: a language model plans the shot, several candidates are rendered, a vision model judges them against a checklist, and defects get a repair pass. Studio images cost 2 credits because the engine does roughly four times the work.

Do credits expire?

No. Buy a pack today, use it next year. There is no subscription and nothing renews automatically.

Can I use the images commercially?

Yes — images you generate are yours to use, including commercially. The Pro pack includes an explicit commercial license certificate for client work.

Is there an API?

Yes. Creator and Pro keys work on the HTTP API — one POST to generate, one GET to fetch the image. See the API docs.

What model does LUMEN use?

The engine is built on FLUX.2-family open-weight models orchestrated by LUMEN's own planning, judging, and repair system. Draft uses a fast distilled model; Studio uses the larger model plus the full pipeline.

Refunds?

If something's wrong, email us within 14 days of purchase and we'll make it right — unused packs are refunded in full.
